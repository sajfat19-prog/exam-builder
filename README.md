# Exam Builder – Update 2

This update extends the existing Arabic/English exam editor while preserving its current visual direction.

## Included
- Question types: sub-questions, multiple choice, true/false, fill in the blanks, matching, and essay.
- Answer areas: none, ruled lines, dotted lines, blank space, answer frame, and calculation/drawing grid.
- Arabic branch labels (أ، ب، ج...) and English branch labels (A, B, C...).
- Section headings and mark display in the exam preview.
- Exam-paper header, student name/exam number lines, paper typography settings, and A4 print styling.
- Automatic local draft recovery for the current language, questions, fields, settings, and active editor/preview screen after refresh.
- Existing themes, dark mode, saved exam library, backup import/export, and print-only view are retained.

## Install on GitHub Pages
Replace the existing project files with the files in this folder, commit to the `main` branch, and wait for GitHub Pages to redeploy.

## Notes
- Drafts and saved exams are stored locally in the current browser/device. This update does not yet add cloud accounts or cross-device synchronization.
- PDF export uses the browser's print dialog; choose “Save as PDF”.
- Official-paper typography and layout are configurable and intended to approximate the supplied ministry exam samples. Exact institutional seals/logos must be supplied by the user if required.
