# Exam Builder – Ministry Sheet Simulation

This update adds a print-preview layout modeled on the user's supplied Iraqi ministry-style exam sheet.

## Included
- A4 portrait page with a double-line border.
- Three-part header: official authority on the right, Bismillah/title/school year in the center, and grade/subject/date/term/time on the left.
- Centered general instruction note with divider rules.
- Right-to-left Arabic question headings with marks separated to the opposite side.
- Compact ministry-style typography and spacing.
- Rendering for branches, multiple choice, true/false, fill-in-the-blank, matching, and essay questions.
- Separate print styling to hide editor controls and print only the paper.

Open `index.html` in a browser. This is a front-end preview; actual print pagination and font availability should be checked in the target browser/printer before official use.
