# منشئ أوراق الامتحانات
واجهة أولية تفاعلية متجاوبة مستوحاة من الصور المرجعية. تدعم اختيار العربية RTL والإنجليزية LTR، إعداد معلومات الامتحان، إضافة الأسئلة والفروع والدرجات، معاينة الطباعة، والحفظ المحلي في المتصفح.

## تشغيل
افتح `index.html` في متصفح حديث. لتثبيت PWA يلزم تقديم المجلد عبر HTTPS أو localhost وإضافة Service Worker في مرحلة النشر.

## ملاحظة مهمة
هذه نسخة واجهة أولية (frontend prototype)، وليست بعد نظاماً متعدد المستخدمين متصلاً بقاعدة بيانات أو تطبيق APK نهائياً. يلزم ربط مصادقة وقاعدة بيانات وخدمة استضافة، ثم تغليف الواجهة كتطبيق Android (مثل Capacitor) قبل النشر العام.
