# ورقتي | WARQATI

مشروع ويب مستقل لإنشاء وتنسيق أوراق الامتحانات.

## الملفات
- `index.html` واجهة البرنامج.
- `styles.css` التصميم والتنسيق والطباعة.
- `app.js` وظائف البرنامج وحفظ العمل والتراجع والإعادة.
- `manifest.json` تعريف التطبيق لإمكانية تثبيته كتطبيق ويب.
- `sw.js` التخزين المؤقت والعمل دون اتصال بعد أول تحميل.

## التشغيل
افتح `index.html` في المتصفح. لا يحتاج المشروع إلى تثبيت مكتبات أو خادم لتجربة الوظائف الأساسية.

## الرفع إلى GitHub
ارفع جميع الملفات الخمسة إلى جذر المستودع، مع الحفاظ على أسمائها. فعّل GitHub Pages من:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

بعد النشر افتح:
`https://USERNAME.github.io/REPOSITORY/`

## المزايا الموجودة
- اختيار العربية أو الإنجليزية واتجاه RTL/LTR.
- ترقيم الأسئلة والفروع تلقائياً: أ، ب، ج للعربية وA, B, C للإنجليزية.
- تعديل السؤال وإضافة الفروع وحذف السؤال.
- اختيار حجم الورقة والخط وحجمه والثيم.
- حفظ تلقائي محلي، مع تراجع وإعادة.
- الطباعة أو الحفظ بصيغة PDF من المتصفح.

## ملاحظة
هذه نسخة تأسيسية متكاملة قابلة للتطوير. بعض خصائص تنسيق الأسئلة المتقدمة والتخطيط المطابق تماماً للنماذج المرجعية تحتاج إلى إضافة بعد إدخال نماذج الورقة النهائية.
