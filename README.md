# منشئ أوراق الامتحانات

واجهة ويب تفاعلية لإنشاء أوراق امتحانات باللغة العربية أو الإنجليزية. تشمل محرر الأسئلة والفروع والدرجات، إعدادات الطباعة، معاينة A4، الثيمات، الوضع الليلي، حفظ الامتحانات محلياً، واستيراد/تصدير نسخة احتياطية.

## التشغيل
افتح `index.html` في متصفح حديث أو انشر الملفات على GitHub Pages.

## ملاحظات المرحلة الحالية
- الحفظ محلي داخل المتصفح والجهاز؛ لا توجد بعد حسابات مستخدمين أو مزامنة سحابية أو قاعدة بيانات.
- زر PDF يستخدم نافذة الطباعة في المتصفح؛ اختر "Save as PDF".
- المشروع واجهة ويب قابلة للتثبيت كـ PWA عند استكمال Service Worker والأيقونات. تغليف Android APK وربط الحسابات والسحابة مراحل لاحقة.
