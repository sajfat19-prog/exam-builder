# ورقتي | WARQATI

مشروع إعادة بناء منظم لإنشاء أوراق الامتحانات.

## الملفات
- `index.html`: واجهة اختيار اللغة والمحرر والمعاينة.
- `styles.css`: الواجهة وتنسيق ورقة الطباعة.
- `app.js`: إدارة الأسئلة والفروع والحفظ والتراجع والاستيراد والتصدير.
- `manifest.json`: تعريف تطبيق الويب.

## التشغيل
افتح `index.html` مباشرة أو ارفع جميع الملفات إلى جذر مستودع GitHub.

## النشر عبر GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root) → Save.

## ملاحظات
النسخة الحالية تعيد بناء الهيكل والوظائف الأساسية وفق المواصفات التي طلبتها. يمكن توسيع تفاصيل أنواع الأسئلة المتخصصة ومطابقة النماذج الوزارية بدقة أكبر في التحديثات التالية.
