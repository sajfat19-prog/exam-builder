# ورقتي | WARQATI — Exam Paper Studio

مشروع واجهة ويب لإعداد أوراق الامتحان ومعاينتها وطباعتها.

## الملفات
- `index.html`: هيكل البرنامج.
- `styles.css`: تصميم الواجهة المتجاوبة.
- `app.js`: منطق الأسئلة والفروع والحفظ والمعاينة.
- `manifest.json`: تعريف تطبيق الويب.

## التشغيل
افتح `index.html` مباشرة، أو ارفع الملفات الأربعة إلى جذر مستودع GitHub Pages مع الحفاظ على أسمائها.

## النشر على GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root) → Save.

## ملاحظات
النسخة تنفذ وظائف بناء الأسئلة والفروع والاختيارات والصح والخطأ والفراغات والمزاوجة والمقالي، إعدادات الورقة، المعاينة، حفظ/فتح JSON والطباعة إلى PDF عبر نافذة الطباعة في المتصفح.
